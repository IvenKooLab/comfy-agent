## Changelog

- **MOSS-Image text-to-image (built in)** (OpenMOSS, Apache-2.0): graph rebuilt to match the official template — SFT int8 UNET + qwen3.5-9b w4a8 text encoder (`CLIPLoader type=moss_image`) + flux2-vae_small; 25 steps er_sde / cfg 2.5 with layer-22 skip-layer guidance. Strong bilingual long-text rendering and layout control
- **FLUX 3 Image Klein text-to-image (built in)** (Black Forest Labs): distilled int8, 16-step euler/simple (swap in the base weights for 50 steps / cfg 3.5); native 4K, text rendering, bounding-box layout, multi-reference editing
- **Two new model suites**: the MOSS-Image files (plus edit and color-depth-control LoRAs) download in one click via hf-mirror; FLUX 3 Klein is listed with honest gating notes — the BFL repo requires signing in to Hugging Face and accepting the license, while the shared VAE still downloads in one click
- **Text override fixed (critical)**: prompt overrides previously leaked into every node holding a `text` input, silently overwriting the negative prompt on dual-CLIPTextEncode graphs; only the first text node is written now, and H3 single-text-node workflows are unchanged
- The Create page ETA hint now follows the selected workflow instead of a hardcoded Flux / 20 steps, and refreshes on mode switch
- Built-in help updated (EN + 中文); roadmap synced with the October ecosystem (NVIDIA VFX nodes, H3 single-head LoRA, the official Comfy Agent naming overlap)
- Test portability fixed: `test_models.py` / `test_upload_media.py` hardcoded a developer-machine path and crashed everywhere else
- 13 new regression tests for the new built-in graphs, model suites and the text-override scoping

Requires ComfyUI ≥ 0.42 for the two new built-in workflows. Full changelog: CHANGELOG.md. Requires local ComfyUI and the WebView2 runtime.

## 更新日志

- 创作页预估提示不再写死「Flux · 20 步」，改为跟随所选工作流，模式切换即刷新

- 测试可移植性修复：`test_models.py` / `test_upload_media.py` 硬编码开发机路径，在别的机器上必崩
