## Changelog

Syncing with the October open-source wave in the ComfyUI ecosystem.

**Highlights**

- **MOSS-Image built-in text-to-image** (OpenMOSS, Apache-2.0): official-template-accurate graph — SFT int8 UNET + qwen3.5-9b w4a8 text encoder (`CLIPLoader type=moss_image`) + flux2-vae_small; 25 steps er_sde / cfg 2.5 with layer-22 skip-layer guidance. Strong bilingual long-text rendering and layout control. Requires ComfyUI ≥ 0.42
- **FLUX 3 Image Klein built-in text-to-image** (Black Forest Labs): 5.6B distilled int8, 16-step euler/simple; native 4K, text rendering, bounding-box layout, multi-reference editing. Requires ComfyUI ≥ 0.42
- **Two new model suites** on the Models page: MOSS-Image files (plus edit / color-depth-control LoRAs) download in one click via hf-mirror; FLUX 3 Klein is listed with honest gating notes (BFL repo requires signing in to Hugging Face and accepting the license — the VAE downloads in one click)
- **Fixed**: prompt (`text`) overrides no longer leak into negative-conditioning nodes on dual-CLIPTextEncode graphs; H3 single-text-node behavior unchanged
- Built-in help updated (EN + 中文)

Download `ComfyAgent-win64.zip`, unzip, double-click. Requires local ComfyUI (127.0.0.1:8188), ffmpeg on PATH, WebView2 runtime. Update ComfyUI to ≥ 0.42 before using the new built-in workflows.

## 更新日志

同步十月开源生态：两条新开源生图线产品化。

**亮点**

- **MOSS-Image 文生图内置**（OpenMOSS · Apache-2.0）：按官方模板还原——SFT int8 主模型 + qwen3.5-9b w4a8 编码器（CLIPLoader type=moss_image）+ flux2-vae_small；25 步 er_sde / cfg 2.5，跳层 22 细节锚定。中英长文本渲染与排版控制强。需 ComfyUI ≥ 0.42
- **FLUX 3 Image Klein 文生图内置**（Black Forest Labs）：5.6B 蒸馏 int8，16 步 euler/simple；原生 4K、文字渲染、边界框排版、多参考图编辑。需 ComfyUI ≥ 0.42
- **模型页新增两个套件**：MOSS-Image 全套（含 edit / 色深控制 LoRA）hf-mirror 一键断点续传；FLUX 3 Klein 如实标注 gated——主模型/编码器需登录 HF 接受协议后手动下载（VAE 可一键下载）
- **修复**：提示词覆盖不再污染双 CLIPTextEncode 工作流的负向编码节点；H3 单文本节点行为不变
- 帮助页同步更新（中英双语）

下载 `ComfyAgent-win64.zip`，解压后双击运行。需要本地 ComfyUI（127.0.0.1:8188）、PATH 中的 ffmpeg 与 WebView2 运行时。使用新内置工作流前请先把 ComfyUI 更新到 ≥ 0.42（启动器页可一键更新）。
