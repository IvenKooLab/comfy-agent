## Changelog

**Full interface localization (Chinese leftovers in English mode cleared)**

- 300+ dynamic and static strings across 9 JS modules and page templates wired into i18n (toasts, confirm dialogs, empty states, status bars, lightbox, diagnostics, inspector)
- All 40+ Q&A in the built-in help page translated to English, switching instantly with the interface language
- Style SOPs, LLM providers and built-in workflow display names localized client-side
- Every component re-renders on a language switch; fixed a cross-language mismatch in the gallery "All" filter

**Environment diagnostics fixed**

- The launcher's "environment diagnostics" showed empty torch / triton / sage versions — a wrong parameter in the probe code meant it had never worked since launch
- When the ComfyUI interpreter path is missing, portable / venv layouts are detected automatically, so the build works when copied to other machines

**Experience**

- Settings page split into grouped cards: connection & directories / AI access / interface & updates
- The gallery empty state gained a "go create" shortcut
- Help page gained Q&A on episode aggregation, priority queueing, audio assets and style digesting (bilingual)

**Download:** attachment `ComfyAgent-win64.zip` (about 40 MB); unzip and run `ComfyAgent.exe` (Windows 10/11, WebView2 required). Data lives in `%APPDATA%/ComfyAgent/data`; replacing the exe keeps your data.
