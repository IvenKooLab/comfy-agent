## Changelog

> **Credit**: the short-drama workflow here follows the hands-on guide by **Miller ([@TuyetloanP81840](https://x.com/TuyetloanP81840))**,
> *"Making an AI short drama alone with Claude + H3"* — identity boards as reference images, three-way dialogue tagging,
> reaction-shot coverage, and the "fix before you re-roll" order. Thank you for publishing the full pipeline and the pitfall list.
> He runs H3 on RunningHub (~¥0.2 per clip); this project runs it on your own GPU.

- **Reference-to-video (ref2v)**: new `H3 参考生视频（9 图 + 3 音频参考）` workflow built on the native `MiniMaxH3ReferenceToVideo` node (up to 9 reference images, 3 reference audios). A shot carrying reference images auto-upgrades to it when queued; unused reference slots are pruned before submit so placeholder images/audio never enter the graph, and the used ones are injected per slot
- **One image, one purpose**: shots accept `refs: [{path, label}]`; on submit the purposes are written into the prompt as the tags the model actually reads (`<Picture 1>` / `<Audio 1>`). Feeding references without referencing them in the prompt is caught by the pre-flight check (`REFS_NOT_REFERENCED`)
- **Dialogue rules**: new `dialogue_stats` plus three checks — dialogue length against shot duration (**~2s per 10 characters**, `DIALOGUE_TOO_LONG`), quoted lines with no "says / inner monologue / off-screen" tag (`DIALOGUE_UNTAGGED`, which is what makes a character speak his own thoughts out loud), and dialogue inside a reaction shot (`REACTION_HAS_LINES`)
- **Shot attributes**: `gen_secs`, `kind` (dialogue / reaction / establishing), `seed`, `audio_refs`, writable through `/api/pipeline/shot`
- **Vertical short drama**: per-batch `aspect` toggle for 9:16 / 16:9, applied to the H3 width/height inputs (352×640 / 640×352, step 32)
- **Subtitles and edit sheet**: `/api/pipeline/srt` exports an SRT built from shot dialogue and durations (AI can't render text reliably — add subtitles in the editor); `/api/pipeline/editsheet` exports a markdown edit sheet (shot no. / kind / duration / dialogue / seed)
- Pipeline UI: aspect toggle, SRT, edit sheet, and a per-shot "Refs" button (pick an image, type its purpose, accumulate up to 9)
- 13 new tests in `tests/test_ref2v_shortdrama.py`; full suite 82 tests plus 3 integration scripts green

Full changelog: CHANGELOG.md. Requires local ComfyUI and the WebView2 runtime.

## 更新日志

> **致谢**：本版短剧链路对照 X 作者 **Miller（[@TuyetloanP81840](https://x.com/TuyetloanP81840)）** 的实操文
> 《用 Claude + H3 一个人拍 AI 短剧：一手实战教程，附全流程提示词和技能包》——身份板当参考图、台词分三种写法、
> 反应镜头补剪、能修就别重抽。**感谢他公开完整流程和踩坑清单。** 他在 RunningHub 上跑 H3（一段约 2 毛），本项目用本机 GPU。

- **参考生视频（ref2v）**：新增 `H3 参考生视频（9 图 + 3 音频参考）` 工作流，基于原生 `MiniMaxH3ReferenceToVideo`（最多 9 张参考图、3 段音频参考）。镜头带参考图时排队自动升级；未用到的参考槽提交前剪枝（占位图/占位音频不进执行图），用到的按槽位注入
- **一图一用途**：镜头支持 `refs: [{path, label}]`，提交时把用途写成模型真正读的标签（`<Picture 1>` / `<Audio 1>`）；喂了图却没在提示词里引用会被预检拦下（`REFS_NOT_REFERENCED`）
- **台词规范**：新增 `dialogue_stats` 与三条检查——台词字数×时长（**每 10 字≈2 秒**，`DIALOGUE_TOO_LONG`）、有引号台词却没标「说/内心独白/画外音」（`DIALOGUE_UNTAGGED`，就是「张嘴念心里话」的元凶）、反应镜头夹台词（`REACTION_HAS_LINES`）
- **镜头属性**：`gen_secs`、`kind`（dialogue/reaction/establishing）、`seed`、`audio_refs`，走 `/api/pipeline/shot` 写入
- **竖屏短剧**：批次 `aspect` 一键 9:16 / 16:9，提交时覆盖 H3 的 width/height（352×640 / 640×352，步长 32）
- **字幕与剪辑单**：`/api/pipeline/srt` 导出 SRT（AI 画字不可靠，字幕留给剪辑软件）；`/api/pipeline/editsheet` 导出剪辑单 markdown（镜头号/类型/时长/台词/seed）
- 管线 UI：比例切换、字幕 SRT、剪辑单、镜头「参考」按钮（选图+填用途，最多 9 张）
- 新增 `tests/test_ref2v_shortdrama.py` 13 项；全套 82 项 + 3 个集成脚本全绿

完整变更：CHANGELOG.md。需要本地 ComfyUI 与 WebView2 运行时。
