## Changelog

- **Models page (nav 9)**: preset suites with one-click resumable downloads (SCAIL-2 bundle included) plus a local model browser
- **Template model check**: opening a template warns about missing models and jumps straight to the downloads
- **Editor media upload**: LoadImage / LoadVideo parameters get an Upload button (straight into the ComfyUI input directory)
- **Official subgraph templates** (SCAIL-2 and others) are flattened automatically for one-click loading
- Settings: one-click open of the native ComfyUI UI; fixed the subtitle-burn auto-popup bug

Full changelog: CHANGELOG.md. Requires local ComfyUI and the WebView2 runtime.
