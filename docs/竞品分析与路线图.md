# 竞品功能差距分析与采用判断

> 2026-08-29 调研。对标对象：可灵创作台、即梦、ComfyUI 生态管理工具（ComfyUI-Manager / Workspace Manager / Asset Library / MixLab）、绘世启动器。
> 判断口径：✅ 值得拿（本地可复刻、产线刚需）；🔶 部分/观望（需模型或较大改造）；❌ 不拿（与本地单机定位冲突）。
> 参考来源：澎湃《可灵vs即梦决战AI短剧》、可灵官方 docs、即梦官网、AMZ123《2026 AI视频创作平台横评》、GitHub 各项目仓库。

## 一、对标云端创作平台（可灵 / 即梦）

| 能力 | 可灵 | 即梦 | 差距判断 | 采用结论 |
|---|---|---|---|---|
| 视频续写/延长（最长3分钟） | ✅ 领先 | 稍逊 | H3 ref2va 传尾帧即"续写"，SOP 化即可 | ✅ 拿：i2v 工作流已内置，补"尾帧续写"专用模式 |
| 口型对齐/台词配音 | ✅ 原声提取+口型驱动 | 近乎完美同步 | 本地无对口型模型（需 LatentSync/类似，量大） | 🔶 观望：先做 TTS 旁白轨 + ffmpeg 混音的轻量替代 |
| 镜头控制（推拉摇移参数化） | ✅ 单次10-15秒 | 部分 | H3 靠提示词运镜描述（已有运镜 SOP 词） | 🔶 半拿：把运镜词做成点选 chips，不建参数化镜头系统 |
| 剧本/分镜模式（节点画布分镜） | ✅ 原生分镜 | ✅ 无限画布分镜节点 | 我们有分集脚本（分镜表结构）+ 队列，缺"剧本→分镜→批量排队"的串联 | ✅ 高价值拿：解析分集脚本生成镜头清单，勾选批量排队（产线刚需） |
| 局部重绘/扩图/消除 | 即梦智能画布 | ✅ | ComfyUI 原生 inpaint/outpaint 节点可用 | ✅ 拿：画廊圈选→重绘/扩图工作流（配合 Flux） |
| 主体参考/角色一致性 | ✅ 智能分镜+主体参考 | ✅ | H3 侧 ref2va 锁脸已有；图像侧缺 IP-Adapter 类模型 | 🔶 需下载模型，等审美 SOP 稳定后再上 |
| 素材库/收藏/标签 | ✅ | ✅ | 画廊已覆盖浏览；缺收藏与标签筛选 | ✅ 小成本拿：收藏星标 + 标签 |
| 4K/超分导出 | ✅ 原生4K | — | RTX VSR 本机已验证（47ms/帧） | ✅ 拿：画廊"AI 放大导出"按钮（RTX VSR） |
| 团队协作/云端 | ✅ | ✅ | 本地单机定位 | ❌ 不拿 |
| 提示词工具（灵感/反推） | 部分 | ✅ | 已有灵感词+GLM 增强；缺"图生文反推" | 🔶 可拿：WD14/joycaption 类本地反推（需下载模型） |

## 二、对标 ComfyUI 生态管理工具

| 能力 | 来源项目 | 差距判断 | 采用结论 |
|---|---|---|---|
| 节点/扩展安装管理 | ComfyUI-Manager | 我们已有启动器节点清单；缺一键安装/更新 | 🔶 拿轻量版：git pull 更新按钮（安装交给 Manager） |
| 工作流文件管理（网格/参数化执行） | Workflow Manager / Workspace Manager | 我们的工作流库已含管理+参数化（检查器）+批量 | ✅ 基本追平，补"工作流收藏置顶" |
| 素材库（图/视频/音频/工作流统一管理） | ComfyUI Asset Library | 画廊已覆盖图/视频；缺音频与工作流预览 | ✅ 补音频分类 |
| 工作流转 APP（分享运行） | MixLab | 需要服务端/分享体系 | ❌ 不拿（本地定位） |
| 启动器（版本/更新/参数配置/日志） | 绘世启动器 | v3.2 启动器页已覆盖：启停/参数/日志/模型/节点/诊断 | ✅ 已拿；可补"ComfyUI git 更新" |
| 多实例/负载均衡 | 一体化管理平台 | 单机单卡 | ❌ 不拿 |

## 三、结论与路线图建议

**v3.3（本次）**：i18n 中英双语、Gitee 检查更新（私有仓手动发包模式）。
**v3.4 建议（小成本高回报）**：
1. 画廊收藏+标签筛选（素材库轻量版）
2. 镜头拼接导出：勾选分镜 mp4 → ffmpeg 拼接成片（产线从"集"到"成片"闭环）
3. AI 放大导出（RTX VSR）
4. i2v"尾帧续写"模式（视频延长）

**v3.5 建议（中期）**：
5. 剧本分镜模式：解析分集脚本 → 镜头清单 → 批量排队 → 完成自动归档（产线核心闭环）
6. 画廊圈选局部重绘/扩图

**观望/不排期**：口型对齐（等本地模型成熟）、主体参考图像侧（等 IP-Adapter 类模型入库）、团队协作（定位冲突）、工作流分享 APP（无服务端体系）。

**判断原则**（后续迭代沿用）：优先做"复用已有 ffmpeg/ComfyUI 能力 + 产线高频动作"的；需要下载大模型或引入服务端的，列观望池等生态成熟。
